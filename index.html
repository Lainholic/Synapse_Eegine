🚀 3단계 초간단 시작법

  1. API Key 입력: 위쪽 [AI 모델 설정]에서 Gemini 또는 OpenRouter API 키를 입력합니다. (기기 내부에만 안전 보관)
  2. 캐릭터 카드 추가: 소장 중인 Tavern V2 카드(.png / .json)를 화면에 드래그하거나 [카드 추가]를 누릅니다.
  3. 대화 시작: 하단 입력창에 지문(*...*)과 대사("...")를 입력하고 전송합니다.

✨ 주요 기능 안내

  • 소설형 지문/대사: 대사는 큰따옴표(""), 지문은 별표(**)로 자동 깔끔 렌더링.
  • 은밀한 속마음: 캐릭터의 히든 속마음(<thought>)은 상단 전용 뷰어에 분리 표시.
  • 모바일 퀵 심볼 바: 키보드 위 원터치 버튼으로 따옴표, 별표, 괄호 즉시 입력.
  • 실시간 대화 검색: 상단 🔍 버튼으로 지난 명장면이나 단어로 즉시 화면 점프.
  • 15턴 자동 요약: 긴 서사도 15턴마다 AI가 3줄 압축하여 장기 기억에 누적.
  • 대화 3대 조작: 답변 재시도는 [🔄 리롤], 오타 수정은 [✏️ 수정], 분기 전환은 [↵ 재전송].

⚠️ 필수 주의사항 & 면책 고지

  • 시크릿 모드 주의: 시크릿 창(InPrivate)으로 접속 시 창을 닫으면 데이터가 즉시 삭제됩니다. 반드시 일반 창에서 이용하세요.
  • 주기적 대화 백업 권장: 캐시 청소 시 대화가 초기화될 수 있으므로 소중한 기록은 [대화 백업 및 내보내기]에서 JSON 파일로 저장해 두세요.
  • API Key 보관: 본인의 API 키는 개인 메모장에 별도 보관해 두시는 것을 권장합니다.
  • 중립 저작 도구 EULA: 본 소프트웨어는 순수 중립 롤플레이 뷰어/저작 도구이며 성인물이나 특정 서사가 번들되어 있지 않습니다. 외부 카드 및 생성물의 법적 책임은 이용자에게 있습니다.
